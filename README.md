\# BRAWLERZ



A 1v1 2d fighting game developed using C# and windows forms.





\## Features

\- Character Selection: 4 characters to select from, with unique move-sets.

\- 1v1 combat

\- Six levels of unique enemies, backgrounds, and music.

\- Enemy attack logic using collision detection.

\- User registration and login

\- Leaderboard: holds username, score, and total rounds played.

\- Story dialogue.

\- Original background music

\- Jump over obstacles mini game

\- backup feature that allows saving and loading data.

\- Volume adjustment using windows media player.



\## Technologies

\- C#

\- Windows Forms



\## Controls

\- WASD - Movement

\- U/I/J/K - Attacks

\- R - Shoot Fireball



\## How to run?

\- Open .sln in visual studio and run application.
